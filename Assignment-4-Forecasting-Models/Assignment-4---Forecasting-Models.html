Model Accuracy Comparison

To compare the forecasting models, the data were divided into a training set and a test set. The models were trained using observations from 2016 through 2024 and used to forecast the 12 months of 2025. These forecasts were then compared with the actual 2025 sales values.

train <- window(electronics_ts, end = c(2024, 12))
test <- window(electronics_ts, start = c(2025, 1))
length(train)
## [1] 108
length(test)
## [1] 12

Forecast the Test Period

mean_test <- meanf(train, h = 12)
naive_test <- naive(train, h = 12)
drift_test <- rwf(train, h = 12, drift = TRUE)
snaive_test <- snaive(train, h = 12)
ets_test <- forecast(ets(train), h = 12)
HW_test <- forecast(HoltWinters(train), h = 12)
ses_test <- ses(train, h = 12)

RMSE Comparison

rmse_results <- data.frame(
  Model = c("Mean", "Naive", "Random Walk with Drift", "Seasonal Naive", "ETS", "Holt-Winters", "Simple Exponential Smoothing"),
  RMSE = c(
    accuracy(mean_test, test)["Test set", "RMSE"],
    accuracy(naive_test, test)["Test set", "RMSE"],
    accuracy(drift_test, test)["Test set", "RMSE"],
    accuracy(snaive_test, test)["Test set", "RMSE"],
    accuracy(ets_test, test)["Test set", "RMSE"],
    accuracy(HW_test, test)["Test set", "RMSE"],
    accuracy(ses_test, test)["Test set", "RMSE"]
  )
)
rmse_results$RMSE <- round(rmse_results$RMSE, 2)
rmse_results

RMSE was used to compare the forecasting accuracy of the models using 2025 as the test period. A lower RMSE indicates better forecasting accuracy. The Seasonal Naive model produced the lowest RMSE of 196.07, followed by ETS with an RMSE of 261.66 and Holt-Winters with an RMSE of 278.98. Therefore, based on RMSE, the Seasonal Naive model was the most accurate model for this dataset. This result suggests that the recurring yearly seasonal pattern is particularly important when forecasting monthly electronics store sales.
